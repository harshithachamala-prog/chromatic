# Chromatic — Exploring Web Development Through Color

Chromatic is a personal project I built to strengthen my understanding of web development by experimenting with interactive UI elements, dynamic data, and real-world application behavior.

I wanted to go beyond simply building static pages and get hands-on experience with how different parts of a web application work together. Through Chromatic, I explored responsive layouts, interactive color selection, reusable UI components, data visualization, and connecting a frontend to a database.

### What I explored
- **Frontend development:** Building responsive layouts and interactive components using React, TypeScript, and CSS.
- **Interactive UI:** Experimenting with custom color selection, HEX values, and live previews.
- **Data visualization:** Displaying community color preferences through rankings, charts, and vote percentages.
- **Database integration:** Using Supabase to store votes and retrieve community results.
- **Dynamic updates:** Updating rankings and statistics as new votes are recorded.
- **UI/UX design:** Practising visual hierarchy, spacing, responsive behavior, and creating a consistent design system.

### Why I built it
I wanted to use a project outside my regular coursework to explore web development concepts I hadn't fully practised elsewhere. Chromatic gives me a space to experiment, make mistakes, understand how things work, and gradually improve both my coding skills and my approach to building user-facing applications.

**Tech stack:** React · TypeScript · Vite · CSS · Supabase · Recharts
